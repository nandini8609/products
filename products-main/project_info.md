# Product Management System

A simple Product Management System developed using Python and SQLite.

## Features

- Add Product
- View Products
- Search Product
- Update Product
- Delete Product
- Manage Price
- Manage Stock Quantity

## Technologies Used

- Python
- SQLite
- GitHub

## Project Files

- `app.py` - Main application
- `database.py` - Database operations

## How to Run

Open the terminal in the project folder and run:

```bash
python app.py
